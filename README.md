
## ZoneWatch — Turn any camera into a smart occupancy sensor (local, no cloud)

**Is my parking spot free? Did a car pull into the driveway? Is the meeting
room actually used?** ZoneWatch answers these questions using cameras you
already own — and never sends a single image to the cloud.

Draw zones directly on your camera image. ZoneWatch's built-in AI watches
each zone and tells you in real time: FREE or OCCUPIED, since when, by what
(car, person, truck…), with full history and statistics.

**Works with what you have:**
- Any RTSP IP camera (Hikvision, Dahua, Reolink, TP-Link, Annke…)
- ESP32-CAM and MJPEG streams
- USB webcams
- Even plain video files
- Runs on any old PC, laptop, mini-PC, NAS or Raspberry Pi — no GPU required
  (uses your GPU automatically when present)

**What you get:**
- Live dashboard with annotated video and per-zone status
- Phone alerts via webhooks; native Home Assistant integration (zones appear
  automatically as occupancy sensors via MQTT)
- Event history with snapshots: "occupied for 2h 14m", busiest-hours charts,
  occupancy percentage
- REST API with API keys for your own integrations
- Login-protected, designed local-first: your video never leaves your network

**What can it detect?** 80 object types, filterable per zone: person, car,
truck, bus, motorcycle, bicycle, boat, cat, dog, horse, cow, sheep, bird,
backpack, suitcase, sports ball, chair, couch, tv, laptop, cell phone,
bottle, cup, and more.

**Use it for:**
- Parking spots, shared driveways, EV charging bays
- Arrival alerts: gate, loading dock, delivery zone
- Desk / meeting room / café table occupancy
- "Person in forbidden zone" safety alerts (workshops, machines)
- Pet detection (cat on the counter again?)
- Counting vehicles or people in any area

**System requirements:** Windows 10/11, Linux (x64/ARM64), macOS — 4 GB RAM,
any dual-core CPU from the last 10 years.

and zones.
